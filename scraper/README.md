# כלי שאיבה מקומי — יד2

כלי שרץ **על המחשב שלך** (לא באתר החי), אוסף מודעות נדל"ן למכירה מיד2,
מסווג אותן לפי הלוגיקה החכמה (מסחרי / יד-שנייה / מחיר למשתכן / חריגים),
ושומר ל‑Excel ו‑JSON.

> ⚠️ הכלי פותח דפדפן אמיתי כדי לעבוד מול הגנות האנטי-בוט של יד2. שאיבה
> אוטומטית מנוגדת לתנאי השימוש של יד2 — השימוש באחריותך.

## התקנה חד-פעמית
מתוך תיקיית הפרויקט:
```bash
npm install -D playwright
npx playwright install chromium
```

## הרצה
```bash
node scraper/yad2.mjs "https://www.yad2.co.il/realestate/forsale?city=5000"
```
- מחליפים את הכתובת בכתובת החיפוש שלך מיד2 (עיר/שכונה/רחוב).
- אם לא מעבירים כתובת — נפתח דף החיפוש הכללי ותוכל לחפש **ידנית** בחלון שנפתח;
  הכלי יאסוף כל מה שייטען.
- החלון נשאר פתוח — התחבר לחשבון שלך ופתור קאפצ'ה אם מופיע, ואז הכלי גולל
  ואוסף אוטומטית.

## הפלט (תיקיית `scraper/output/`)
- `yad2-<תאריך>.xlsx` — Excel עם גיליונות: מודעות מסווגות, סיכום השוואתי,
  מחיר למשתכן, חריגים.
- `yad2-<תאריך>.json` — הנתונים המנורמלים.
- `yad2-<תאריך>.raw.json` — גיבוי גולמי של תגובות ה‑API (למקרה שהנירמול פספס שדה).

## חיבור לאתר
את קובץ ה‑JSON/Excel אפשר לטעון לאתר לצורך השוואת **מחיר מבוקש (יד2)** מול
**מחיר סגירה (רשות המסים)**. אם תרצה שאוסיף כפתור "העלה קובץ יד2" באתר — בקש.

## הערות
- ליד2 יש הגנות אנטי-בוט שמשתנות; ייתכן שיהיה צורך לכוונן את הסלקטורים/הזמנים.
- אם `output` ריק — פתח את `raw.json` לראות מה חזר, ונעדכן את הנירמול.
